# เจอกู

เว็บทำมีม "เป็นไงล่ะไอสัส เจอกู" จากรูปของตัวเอง ใส่ได้ 1-3 รูป (เรียงต่อกันแนวตั้ง ครอปเป็น 16:9 หรือ 1:1 แล้วลากเลือกส่วนที่จะให้เห็นได้) แล้วโหลดได้เลย
ทุกอย่างทำในเบราว์เซอร์ รูปไม่ถูกส่งไปไหน

https://ssupawat.github.io/jergu/

## ไฟล์

- `index.html` หน้าเว็บทั้งหมด (HTML+CSS+JS ไฟล์เดียว ไม่ต้อง build)
- `og.png` รูปพรีวิวตอนแชร์ลิงก์ (พื้นม่วง มีแต่ตัวหนังสือ)
- `favicon.svg` ไอคอนแท็บ
- `.nojekyll` บอก GitHub Pages ไม่ต้องแปลงไฟล์

## Deploy

GitHub Pages จาก branch `main` โฟลเดอร์ root แก้ไฟล์แล้ว push ขึ้น `main` เว็บจะอัปเดตเองในประมาณ 1 นาที

## หมายเหตุ

- ปุ่ม "แชร์" จะโผล่เฉพาะบนมือถือที่เบราว์เซอร์ส่งรูปเข้าแอปอื่นได้ (เช่น LINE, IG) บนคอมจะมีแค่ปุ่มโหลดรูป
- ฟอนต์ Kanit/Sarabun โหลดจาก Google Fonts
- ในเว็บไม่มีรูปของใคร ผู้ใช้ต้องใส่รูปเอง
